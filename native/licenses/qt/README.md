# Qt runtime notices

These are the verbatim LICENSES directories from the official Qt qtbase and qtsvg repositories at v6.12.0. SOURCES.json records the source URLs, upstream Git blob identities and SHA-256 digests. They cover the modules/plugins used by the current Windows packaging path; they are not a claim that every SDK module is redistributed.

Qt is dynamically linked. Replaceable Qt DLLs and their matching plugins remain separate from TideTerm.exe. Corresponding Qt source is available from the official versioned repositories:

- https://code.qt.io/cgit/qt/qtbase.git/tree/?h=v6.12.0
- https://code.qt.io/cgit/qt/qtsvg.git/tree/?h=v6.12.0

Qt licensing and third-party attribution information:

- https://doc.qt.io/qt-6.12/licensing.html
- https://doc.qt.io/qt-6.12/licenses-used-in-qt.html

Application source and build instructions are included by reference in the package build-info.txt. Review the license terms for the actual artifact being distributed; a source inventory or SBOM alone is not a compliance certification.
