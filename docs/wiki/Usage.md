# 使用与限制 / Usage

以下说明当前实现的入口与语义，不代表所有协议、平台和外部程序均已完整验收。

## 会话与工作区

快速连接或会话树可创建本地 Shell、SSH，以及基础 Telnet/串口/TCP 会话。SSH 连接需核对主机密钥指纹；密码、私钥和交互认证按实际目标选择。多标签、标签组与分屏可组织独立会话；同步输入需明确选择目标，发送前确认当前范围。

“会话”菜单可保存/恢复工作区、重新打开已关闭标签（Ctrl+Shift+T）。恢复重新创建进程和连接，不复活原进程、终端输出或未保存的发送草稿；未记住的凭据仍需重输。

## 阅读与检索

支持搜索、阅读模式、矩形/多重选择、命令块、嵌套输出折叠和文本标记。部分命令边界与当前目录能力依赖受支持 Shell 的报告；不能假定任意嵌套 Shell 或远端程序均有精确语义。

手动折叠需属于一个已完成命令的输出，支持嵌套/独立范围，拒绝交叉、跨命令等不明确输入；每窗格最多 128 个范围、8 层。文本标记每窗格最多 16 条。来源内容或布局变化后，失效映射保守撤销。

## Sender 与补全

发送栏支持草稿、历史、模板及显式的 Shell 环境查询。路径、程序目录、Git、Docker 和 kubectl 来源按各自前提启用，选择候选通常只填入草稿，不自动执行。

不要把本地路径补全用于终端里手动进入的远端 Shell。SSH SFTP 与 Shell 可能处于不同命名空间。程序目录建议不读取全部 PATH，也不证明程序可执行。Shell、Docker、kubectl 查询会向当前通道实际发送命令，需要预览和空提示符确认；凭据插件或远端认证可能有外部副作用，按界面提示决定。

## 文件与传输

本地/SFTP 浏览器提供创建、移动、复制、删除、上传/下载；批量操作最多 16 个根项目，目录递归不跟随链接，冲突策略与取消由任务反馈。目录任务不提供普通文件传输的暂停/续传。

远端编辑先下载隔离文本副本，再由用户明确“检查并回传”；远端元数据改变时拒绝覆盖。SFTP v3 替换通过保留原件、提交和失败恢复处理，不是服务器事务。失败后按反馈检查保留的备份。

## 日志与历史浏览

“会话 → 日志”显式开始、暂停、恢复、停止。后台持续记录独立于内存预览，默认按 8 MiB 轮换并保留五份；设置可调整。暂停期间不记录，停止等待排空，写入错误会反馈。轮换不是全局磁盘配额，旧记录目录不会自动删除。

终端右键“历史导出与浏览…”可后台导出主屏历史快照、临时分页或交给明确选择的 less/nvim。默认磁盘预算 512 MiB；只读 mmap 需显式启用且临时文件至少 200 MiB。使用完毕按界面关闭/取消清理临时文件。

“tmux 会话…”预览后向当前空 POSIX 提示符发送一次附加、分离或服务端历史浏览命令。目标需安装 tmux，历史浏览还需 less/mktemp。这是普通终端客户端附加，未实现 tmux 原生布局/窗格同步。

## 平台与隐私

中英文界面、明暗主题在 Qt 主线维护。Windows 是主要开发平台；Linux/WSL 开发构建、macOS、Wayland、真实系统 IME、外部 SSH/TUI 和长时运行分别需要验证，不根据 offscreen 成功推导全面兼容。

日志、导出与截图可能含敏感终端内容。提交反馈时使用隔离配置与合成数据。可选 AI API 会把选定上下文发给配置的服务，发送前核对内容、范围和命令。
