# Contributing to TideTerm

TideTerm is a personal project in active development. Focused bug reports, fixes and documentation improvements are welcome.

1. Describe the problem and expected user behavior; use synthetic data in reproductions.
2. Work on a topic branch from `master`. Keep changes focused and preserve third-party notices.
3. Run the checks appropriate to the changed module; list commands, results and anything untested in the PR. See [Development](docs/wiki/Development.md).
4. Include screenshots for UI changes and matched workload/environment details for performance claims. Never include credentials or private terminal contents.
5. Use Conventional Commit messages and request human review before merging.

The project uses AI-assisted development. AI-assisted contributions follow the same review, provenance and validation expectations. Adding an AI feature must make external data transfer and execution explicit to the user.

Read [Build](docs/wiki/Build.md), [Architecture](docs/wiki/Architecture.md), [third-party notices](THIRD_PARTY_NOTICES.md) and [Security](SECURITY.md). Own contributions are provided under [Apache-2.0](LICENSE); third-party code keeps its original terms.
